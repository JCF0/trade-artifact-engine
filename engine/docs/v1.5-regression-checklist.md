# v1.5 Regression Checklist

## Deterministic Automated Suites

Run:

```bash
node engine/src/run-v15-regression.mjs
node engine/src/check-v15-demo-flow.mjs
node engine/src/run-v14-regression.mjs
```

Expected:
- all suites pass
- demo checker passes against the tracked sample manifest and matching local inventory
- no live Helius, upload, mint, signing, browser automation, or remote deploy assumptions
- non-zero exit on failure

## Demo Checker Scope

Verify:
- `engine/samples/sample-gallery.manifest.json` contains at least one receipt hash
- the first manifest `receipt_hash` exists in local inventory before route checks begin
- `/api/gallery` returns `200 application/json`
- `/api/gallery/preview` returns `200 text/html`
- `/api/proof/:receiptHash` returns `200 application/json`
- `/api/verifier/:receiptHash` returns `200 application/json`
- `/api/proof/:receiptHash/card` returns `200 application/json`
- `/api/proof/:receiptHash/card/preview` returns `200 text/html`
- `/api/proof/:receiptHash/hosted-preview` returns `200 text/html`
- no unexpected fetch/network behavior occurs during checks
- no writes, browser automation, screenshots, or publish/export side effects occur during checks

## Manual Smoke

1. Start the local API server with local inventory that matches `engine/samples/sample-gallery.manifest.json`.
2. Open `/api/gallery/preview` and confirm the page frames itself as a sample gallery, not a hosted platform, leaderboard, profile, portfolio, or mainnet product.
3. Follow links to proof detail, verifier JSON, card JSON, card preview, and hosted preview.
4. Confirm selected-receipt and raw-quote disclosures are present on the relevant surfaces.
5. Confirm redacted and truncated wallet display states render correctly on gallery/card surfaces without leaking the full wallet.
6. Confirm hosted preview remains local hosted-style preview semantics only and does not imply remote hosting or server-side privacy guarantees.
7. Confirm browsing routes do not create local output directories.
8. Confirm the tracked sample manifest is the source of the demo receipt.

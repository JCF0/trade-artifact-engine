# v1.5 Regression Checklist

## Deterministic Automated Suites

Run:

```bash
node engine/src/run-v15-regression.mjs
node engine/src/check-v15-demo-flow.mjs
node engine/src/run-v14-regression.mjs
```

Expected:
- all suites pass
- demo checker passes against the tracked sample manifest
- no live Helius, upload, mint, signing, browser automation, or remote deploy assumptions
- non-zero exit on failure

## Demo Checker Scope

Verify:
- sample manifest contains at least one receipt hash
- `/api/gallery` returns `200 application/json`
- `/api/gallery/preview` returns `200 text/html`
- `/api/proof/:receiptHash` returns `200 application/json`
- `/api/verifier/:receiptHash` returns `200 application/json`
- `/api/proof/:receiptHash/card` returns `200 application/json`
- `/api/proof/:receiptHash/card/preview` returns `200 text/html`
- `/api/proof/:receiptHash/hosted-preview` returns `200 text/html`
- no unexpected fetch/network behavior occurs during checks

## Manual Smoke

1. Start the local API server.
2. Open `/api/gallery/preview`.
3. Confirm the page frames itself as a sample gallery, not a leaderboard, profile, or portfolio surface.
4. Follow links to proof detail, verifier, card JSON, card preview, and hosted preview.
5. Confirm selected-receipt and raw-quote disclosures are present on the relevant surfaces.
6. Confirm browsing routes do not create local output directories.
7. Confirm the tracked sample manifest is the source of the demo receipt.

# Artifact v1.5 Sample Gallery Surface

## Scope

Slice 4 adds a local, read-only sample gallery for curated Artifact proof receipts.

Routes:
- `GET /api/gallery`
- `GET /api/gallery/preview`

This slice is a browse/demo surface only.
It is not a leaderboard, ranking page, profile surface, portfolio view, or hosted service.

## Manifest

Tracked manifest path:
- `engine/samples/sample-gallery.manifest.json`

`engine/data/` is gitignored, so the gallery manifest lives under `engine/samples/` instead.

Manifest shape:

```json
{
  "version": "1.0.0",
  "title": "Artifact Sample Gallery",
  "receipt_hashes": [
    "<receipt_hash>",
    "<receipt_hash>"
  ]
}
```

Rules:
- manifest order wins when present
- unknown receipt hashes are ignored
- fallback inventory order is stable and follows inventory ordering

## Behavior

- local inventory-backed only
- read-only
- no writes or file creation during request handling
- no network calls
- no legacy `verification_hash` fallback
- empty gallery returns and renders cleanly
- no ranking or portfolio semantics

## HTML Preview

The preview route renders a standalone local HTML page with:
- title and subtitle
- selected receipt / raw quote disclosures
- compact per-item cards
- links to proof, verifier, card JSON, card preview, and hosted preview

It omits:
- ranking language
- leaderboard/profile/account language
- wallet totals or performance summaries
- lifecycle/upload/mint rows
- artifact URI grids
- scripts, external CSS, and external assets

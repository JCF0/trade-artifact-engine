# v1.7 Regression Checklist

Run from the repository root.

## Required Commands

```bash
node engine/src/run-v17-regression.mjs
node engine/src/check-v17-coverage-demo.mjs
node engine/src/run-v16-regression.mjs
node engine/src/check-v16-receipt-board-demo.mjs
node engine/src/run-v15-regression.mjs
node engine/src/run-v14-regression.mjs
```

## Required Coverage Checks

The v1.7 regression and demo checker must verify:
- proof-detail and verifier core `coverage_statement` deep-equal for the same receipt
- proof-detail and verifier `publication_context` is `null`
- receipt-board coverage has board-only publisher context
- proof-card JSON includes compact `coverage_summary`
- card preview, board preview, hosted-preview, and static export include compact coverage wording
- hosted-preview and static export do not include board publisher wording
- missing timestamps produce incomplete coverage without changing route success or board eligibility
- mixed-quote/unverified receipts remain excluded
- compact coverage sections do not expose coverage codes, verifier diagnostics, wallet addresses, PnL/USD amounts, upload fields, mint fields, or signing fields
- demo checker observes zero fetch calls
- demo checker observes no filesystem changes

## Exclusions

Do not include:
- live Helius
- upload, mint, or signing
- browser automation
- remote deployment
- child-process ledger runner
- gallery coverage changes
- normalization changes

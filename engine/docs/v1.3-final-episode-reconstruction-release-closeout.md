## Implemented subset

### Qualified *calibration-only* retained-byte format

`loadRetainedEpisodePackageV1({ root, expected_manifest_sha256 })` reads a Linux, explicit absolute-root, **flat directory** format. The external expected digest is mandatory; no latest-file discovery or environment-selected root is used.

`manifest.json` has exactly:

- `version`: `artifact_retained_episode_package_v1`.
- `members`: ascending, unique records with exactly `path`, `bytes`, and `sha256`.

Members use restricted ASCII basenames. Subdirectories, traversal, symlinks, hardlinks, nonregular files, duplicate/unknown inventory entries and unknown manifest fields refuse loading. The root is held by a directory descriptor; member reads use its Linux `/proc/self/fd` path and `O_NOFOLLOW`. This avoids redirecting reads through a replaced named root. Bounded descriptor reads verify type, identity, length, metadata and byte digest. Loaded bytes are retained in private memory; caller reads receive independent copies.

Bounds: 8 MiB per member, 64 MiB aggregate, 256 KiB manifest; the inventory scan permits at most 512 total directory entries, including the manifest. JSON parsing bounds depth and nodes, rejects duplicate keys, invalid UTF-8, malformed JSON, nonfinite values, negative zero and unsafe integer Numbers. The existing `rentEpoch` exact-u64 representation is supported from original integer tokens as a decimal string. Original raw files are never rewritten or repaired.

A loader success proves byte/package integrity, **not acquisition truth**. The reconstruction entry currently admits only the explicitly named calibration profile and two independently pinned retained transaction response bodies. It does not provide a generic source-authority callback or admit a purported final-episode profile by checksum alone.

# v1.4 Limitations

## Local Only

v1.4 produces static hosted/unlisted proof-page bundles locally, but does not deploy them remotely.
The hosted-preview API is preview-only and is not a hosted proof delivery service.

## Visibility Semantics

- `unlisted` is not private. Anyone with the link can view.
- `private` means local draft semantics only. It does not imply server-side privacy or access control.
- `public` changes framing only. It does not add deployment.

## Proof Scope

- Raw quote only. No USD normalization.
- Selected receipt only. Not a full track record or portfolio statement.
- Wallet display may be `truncated`, `redacted`, or `full` at publish time.
- Wallet display policy is render-only. It does not modify canonical receipts or verifier outputs.

## Out of Scope

v1.4 does not add:
- account login
- wallet linking
- mainnet release workflows
- upload
- mint
- signing
- price fetching
- Helius balance-at integration
- remote deployment

## Output Safety

- Generated `published/` and `drafts/` outputs live under `engine/data` by default and should not be committed.
- `--out` can write outside `engine/data`; use it carefully.
- `--force` overwrites only the three managed files and does not clean arbitrary extra files.

## Legacy Scope

Legacy v1.1 remains non-default and separate. Hosted preview and publish flows do not use legacy lookup by default.

# Trade Artifact Engine — v1.2 Known Limitations

## Network

- **Solana devnet only.** No mainnet approval exists. Mainnet upload and mint require separate explicit approval gates that are not implemented.
- All uploaded artifacts and minted tokens are on devnet.

## Metadata

- **Metadata linkage is manifest-only.** The metadata URI is recorded in the local mint result manifest but is NOT attached on-chain via Token-2022 metadata pointer or Metaplex Token Metadata program.
- **No Metaplex Token Metadata integration.** Standard NFT explorers and marketplaces may not display the token's metadata automatically.
- **No hosted public proof page.** `external_url` is `null` in all metadata. There is no web UI for viewing proof receipts.

## Valuation

- **Raw quote valuation only.** All PnL values are denominated in the trade's native quote currency (SOL, USDC, USDT). No USD normalization is applied.
- **No price oracle.** No live or historical price fetching exists. No SOL→USD, USDC→USD, or any cross-currency conversion.
- For USDC/USDT-quoted receipts, `quote_is_usd_stable: true` is contextual metadata only — it does NOT imply USD-normalized PnL.

## Minting

- **No batch minting.** Each mint run processes exactly one receipt via `--mint-receipt-id`.
- **No `--mint-force` override.** Once a receipt is minted, the adapter skips it on re-run. There is no override to re-mint.
- **No mainnet mint.** The `non_devnet_not_approved` gate blocks any non-devnet mint.
- **Token-2022 NonTransferable extension.** Minted proof tokens cannot be transferred after creation. This is by design — proof receipts are non-transferable.

## Accounting / Ledger

- **Swap events only.** The position ledger processes normalized swap events. Transfers, airdrops, staking rewards, and other non-swap token movements are not accounted for.
- **Single-wallet assumption.** The pipeline processes one wallet at a time. Cross-wallet position tracking is not supported.
- **External transfer flag.** Sells exceeding observed inventory are flagged as `partial_history` / `external_transfer_possible` but not automatically resolved.

## Upload

- **Irys/Arweave devnet only.** Uploads go to Irys devnet. Mainnet Arweave permanence requires separate funding and approval.
- **SVG images only.** v1.2 renders receipts as SVG. PNG rasterization is not implemented (v1.1 has separate PNG rendering for its own receipts).

## Debug Artifacts

- **Generated debug artifacts are local only.** Files under `engine/data/debug/` are wallet-specific, run-specific, and may contain real wallet addresses and transaction hashes. They should not be committed to version control unless explicitly intended.

## v1.1 Compatibility

- **v1.1 pipeline behaviour is preserved and untouched.** The v1.2 ledger/receipt/verification chain runs entirely under the `--ledger-debug` flag. Without it, only the v1.1 pipeline executes.
- v1.1 and v1.2 receipt schemas are separate and independent. v1.2 does not modify v1.1 receipts, hashes, or verification logic.

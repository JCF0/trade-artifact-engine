# Artifact v1.15 Release Notes (Draft — Slice 9)

## Changed

- The production controlled-live operator now constructs `wallet_wide_acquisition_request_v2`, creates provider port v2, and runs the full-transaction acquisition/projector path.
- Bulk enrichment is fixed to `https://mainnet.helius-rpc.com/` and `getTransactionsForAddress` with `transactionDetails: "full"`, `commitment: "finalized"`, `encoding: "json"`, `maxSupportedTransactionVersion: 0`, `tokenAccounts: "none"`, `status: "any"`, `sortOrder: "desc"`, and page size: 100 with opaque pagination.
- Finalized `getTransaction` is available only as an explicitly budgeted missing-signature-only fallback.
- Controlled-live reports use `artifact_v1.15_controlled_live_validation_v1` and expose full-transaction page/entry/reconciled counts plus exact-fallback requested/reconciled counts.
- The fixed diagnostic vocabulary covers full-transaction history, projection, and fallback failures while retaining `provider_value_unsafe` precedence.
- `engine/docs/v1.15-provider-compatibility.md` provides the dated, commit-bound pre-live STOP checklist. The Slice 9 review date is `2026-08-11`, bound to baseline commit `aee2e8250ae2ae5ab42a8a75038b9b3f321dc7e9`; a fresh clean release-candidate binding remains mandatory before live operation.

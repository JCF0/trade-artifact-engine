## Architecture

```
Normalized Events
  → Position Ledger (WACB accounting)
    → Receipt Candidates (B1)
      → Canonical v1.2 Receipts (B2)
        → Receipt Verifier (B3)
        → Valuation Validation (C1/C2)
        → Preview / HTML / SVG (D1/D2/E3)
        → Metadata Scaffold (E1)
        → Upload Package + Templates (E4)
        → Upload Dry Run (E5)
        → Live Upload via Irys (E6/E7)
        → Mint-Ready Resolver (E8)
        → Token-2022 Devnet Mint (E9)
        → E2E Proof Manifest (F)
```

All ledger/accounting/verification modules are pure functions with zero I/O.
Upload and mint modules use lazy imports and strict gates.

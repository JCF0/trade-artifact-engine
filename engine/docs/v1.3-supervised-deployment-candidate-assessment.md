- It takes `request.endpoint`; the composed scheduler currently receives the literal compatibility label `OFFLINE_INJECTED_PRIMARY_SOLANA_RPC` (`A/wiggles-submission-v1.mjs:461–464`). That label is not a routable endpoint or evidence that an actual provider is selected. - It calls `response.arrayBuffer()` before returning the complete body. It has no streaming byte ceiling. The composed wrapper checks response length only afterward (:445). Do not call this bounded network memory use.
- Its private controller is not linked to the enclosing `request.signal`; an outer abort therefore is not proved to cancel its socket/body read. It offers one fetch call but has not established the runtime HTTP client's internal retry, proxy, DNS/TLS, decompression or redirect behavior on this host.
- Readiness needs string responses for `{body, signal}`; simulation/source use `{body, signal, request_bytes}` and expect exact raw bytes; submission needs `{status, body: Buffer}` over `requestBody`. These contracts require deliberate trusted adaptation, not passing one fixture callback everywhere.

`A/supervised-rpc-v1.mjs:22–87` establishes logical call budgets, request-before-effect retention, absolute/monotonic checks, AbortSignal propagation and late-publication refusal. It still hands work to an injected function and bounds the body after return (:72–78). The final exchange must preserve bytes actually sent and tie transport diagnostics to these existing records, without falsely claiming the current wrappers already prove all wire behavior. ### Provision, stop and restart semantics

Provision authority **and** supervision head explicitly once before normal launch. A crash between those two operations is a provisioning failure, not permission for launch to complete or recreate them. Administrator records that disposition and stops; there is no automatic reenrollment. Runtime calls only existing-state open APIs. Missing/corrupt/blank/inconsistent state or head blocks. The journal cross-checks phase markers against its hash-linked records/head (`A/supervised-journal-v1.mjs:27–94`); SQLite uses WAL/FULL and validates schema/ownership/state (`A/sqlite-decision-authority-v1.mjs:474–549`).

No process exit proves “nothing signed.” On stop, close further decision admission and prevent new signing/send initiation; retain in-flight evidence and service authenticated revocation where possible. Revocation cannot recall escaped bytes. Confirm its durable result, not merely delivery; export must refuse when committed revocation wrapper evidence is missing (B3), and identical replay must retain every delivery (B5).

Normal reopen preserves consumption and does not adopt cached readiness. A phase already claimed is not refilled; a consumed ordinal is not another decision. Private production construction also requires `now >= not_before` and `now < acquisition_not_after`, and runtime configuration requires the common deadline to remain live (`A/wiggles-production-configuration-v1.mjs:26`; runtime :140–142). Consequently this factory is **not a universal after-window recovery opener**. Do not widen deadlines or reinterpret the acquisition-specific limit as a new disposal mandate to make recovery launch. Preserve/reconstruct available evidence offline; any missing recovery acquisition harness is separately scoped read-only work.

Known valid-snapshot restoration, reprovisioning, authoritative-state loss or ambiguous custody means execution STOP. Automatic administrator-snapshot rollback detection is excluded by `D/v1.3-bounded-agent-rollback-deployment-decision.md:3–9` and `D/v1.3-construct-supervised-release-checklist.md:3–11`.

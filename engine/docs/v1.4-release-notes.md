# v1.4 Release Notes

## Summary

Artifact v1.4 finishes the local hosted-proof scaffold layer.

It adds:
- hosted proof-page render context with explicit visibility framing
- render-only wallet display policy (`truncated`, `redacted`, `full`)
- opaque publish slugs
- in-memory publish bundle generation for `index.html`, `proof.json`, and `manifest.json`
- local filesystem publish CLI with dry-run default and explicit `--write`
- read-only hosted-preview API for local HTML preview
- deterministic v1.4 regression coverage

## What v1.4 Does

v1.4 can now:
- build hosted-style proof HTML locally
- build static proof bundles locally
- preview hosted framing over HTTP locally
- write publish bundles to local disk only when explicitly requested

## What v1.4 Does Not Do

v1.4 does not add:
- remote deployment
- hosted service infrastructure
- account login or wallet linking
- upload, mint, or signing behavior
- mainnet workflows
- price fetching or USD normalization
- Helius balance-at integration

## Key Commands and Routes

Local publish CLI:
- `node engine/src/proof-publish/cli.mjs --receipt-hash <hash>`
- `node engine/src/proof-publish/cli.mjs --receipt-hash <hash> --write`

Local hosted preview API:
- `GET /api/proof/:receiptHash/hosted-preview`

Regression:
- `node engine/src/run-v13-regression.mjs`
- `node engine/src/run-v14-regression.mjs`

## Visibility Notes

- `unlisted` is not private
- `public` uses public hosted framing
- `private` means local draft semantics only and does not imply server-side privacy

## Output Safety

By default, generated publish outputs live under:
- `engine/data/published`
- `engine/data/drafts`

These are local generated artifacts and should not be committed.

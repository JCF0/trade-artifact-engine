# Artifact v1.10 Release Notes

Artifact v1.10 adds deployment-readiness for the local static public-demo bundle.

## Added

- Deterministic public-demo bundle generation for the selected Historical Verified Receipt Board.
- Static Cloudflare Pages metadata files:
  - `_headers`
  - `robots.txt`
  - `404.html`
- A deterministic predeploy checker for the generated bundle.
- A v1.10 regression runner that carries forward v1.9 deterministic coverage and adds public-demo closeout checks.

## Preserved

- Publisher-selected JUP and RAY receipts only.
- Verified `closed_position` receipts only.
- Truncated wallet display by default.
- Receipt-scoped Coverage Statements.
- Raw quote only; no USD normalization.
- No runtime server, database, accounts, signing, upload, minting, wallet connect flow, mainnet action, Cloudflare API call, GitHub integration, DNS, or deployment automation.

## Manual Hosting Target

The intended first hosted review target is a dedicated Cloudflare Pages Direct Upload project using the default `pages.dev` URL. Upload only the contents of `engine/data/public-demo` after the predeploy checker passes.

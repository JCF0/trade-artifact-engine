# v1.4 Regression Checklist

## Deterministic Automated Suites

Run:

```bash
node engine/src/run-v13-regression.mjs
node engine/src/run-v14-regression.mjs
node engine/src/api/proof-hosted-preview-api.test.mjs
```

Expected:
- all suites pass
- no live Helius, upload, mint, signing, or remote deploy assumptions
- non-zero exit on failure

## Hosted Preview Checks

Verify:
- known receipt returns `200 text/html`
- unknown receipt returns `404`
- invalid `visibility` returns `400`
- invalid `wallet_display` returns `400`
- invalid `base_url` returns `400`
- `unlisted` framing includes the unlisted disclosure
- `public` framing omits the unlisted disclosure
- `private` framing uses local draft/private-semantics wording only
- truncated/redacted wallet display does not leak the full wallet
- hosted preview creates no files or directories

## Publish CLI Checks

Verify:
- dry-run is the default
- no writes occur without `--write`
- unlisted/public write under `engine/data/published`
- private writes under `engine/data/drafts`
- `--force` overwrites only managed files

## Manual Smoke

1. Start the local API server.
2. Open `/api/proof/:receiptHash/hosted-preview` with `unlisted`, `public`, and `private` visibility.
3. Confirm raw quote and selected-receipt disclosures are present.
4. Confirm preview requests do not create `published/` or `drafts/` directories.
5. Run the publish CLI in dry-run mode.
6. Run the publish CLI with `--write` and inspect the bundle files.

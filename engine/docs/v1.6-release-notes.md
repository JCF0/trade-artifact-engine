# v1.6 Release Notes

## Summary

Artifact v1.6 adds a local Historical Verified Receipt Board prototype.

The board orders selected verified receipt entries. It does not rank traders, wallets, profiles, portfolios, skill, prize eligibility, or full track records.

## What v1.6 Adds

v1.6 adds:
- tracked receipt-board manifest contract
- receipt-board view model
- standalone receipt-board HTML renderer
- local read-only receipt-board API routes
- deterministic v1.6 regression runner
- receipt-board demo checker

## Routes Added In v1.6

- `GET /api/receipt-board`
- `GET /api/receipt-board/preview`

## Ranking Boundary

Default ranking metadata:
- `metric`: `trust_then_time`
- `rank_subject`: `receipt`
- `pnl_scope`: `none`

v1.6 does not add PnL ranking, USD normalization, trader ranking, wallet ranking, profile ranking, portfolio ranking, or skill ranking.

`wallet_display=full|truncated|redacted` is validated for forward compatibility. Current board rows do not expose wallet fields, so this option is effectively a no-op for the board.

When `limit` or `offset` is used, `count` currently reflects returned paged rows, not total ranked rows.

## Sample Set Boundary

The tracked manifest is publisher-selected unless a future explicit coverage scope is supplied.

v1.6 does not claim:
- live trading support
- prize eligibility
- anti-wash-trading analysis
- public competition readiness
- full-track-record coverage
- account/profile identity
- remote hosting or wallet signing

## Key Commands

Regression:
- `node engine/src/run-v16-regression.mjs`
- `node engine/src/run-v15-regression.mjs`
- `node engine/src/run-v14-regression.mjs`

Demo checker:
- `node engine/src/check-v16-receipt-board-demo.mjs`
- requires local inventory containing the first `receipt_hash` from `engine/samples/historical-receipt-board.manifest.json`

Optional ledger runner remains separate:
- `node engine/src/ledger/run-all-tests.mjs`

# Artifact v1.5 Proof Card Surface

## Scope

Slice 3 adds a compact, shareable proof card surface for one inventory-backed receipt.

Routes:
- `GET /api/proof/:receiptHash/card`
- `GET /api/proof/:receiptHash/card/preview`

This slice is:
- read-only
- local only
- additive to existing proof detail and verifier surfaces
- limited to selected-receipt summary semantics

It does not:
- modify canonical v1.2 receipt schema, hash, accounting, or verifier logic
- add uploads, minting, signing, accounts, profiles, leaderboards, remote hosting, gallery grids, or network verification
- reinterpret `raw_quote`

## Data Source

The card view-model is built from the existing proof-detail view-model and may apply the existing wallet display policy for rendering.

No additional verifier execution, upload execution, mint execution, file creation, or network fetch occurs during request handling.

## Behavior

- `200` for known canonical `receipt_hash`
- `404` for unknown well-formed `receipt_hash`
- `400` for malformed `receipt_hash` when validating `^[a-f0-9]{64}$`
- no legacy `verification_hash` fallback
- no writes, file creation, upload, minting, signing, or network calls

## Renderer Scope

The HTML preview is a standalone, single-card document.

It includes:
- title and subtitle
- token display
- receipt type
- display status
- verification status
- trust label
- short receipt hash
- valuation status
- verifier path
- disclosures

It omits:
- proof lifecycle tables
- upload or mint rows
- artifact URIs
- hosted visibility semantics
- scripts, external CSS, and external assets

# Artifact v1.10 Public Read-Only Demo

Artifact v1.10 adds a deterministic local static bundle for an unlisted public demo.

## Build Commands

Dry run:

```bash
node engine/src/public-demo/cli.mjs --dry-run
```

Write:

```bash
node engine/src/public-demo/cli.mjs --write --out engine/data/public-demo --visibility unlisted --wallet-display truncated
```

Use `--force` only to replace a non-empty output directory.

## Output

The bundle contains:

- `index.html`
- `board.json`
- `manifest.json`
- `receipts/<slug>/index.html`
- `receipts/<slug>/proof.json`
- `receipts/<slug>/manifest.json`
- `verifier/<receipt_hash>.json`

Only the two publisher-selected JUP and RAY receipt hashes from `engine/samples/historical-receipt-board.manifest.json` are eligible for the public demo bundle.

## Safety Boundaries

The builder fails closed unless every selected receipt is:

- `closed_position`
- `verification_status=verified`
- hash-valid, schema-valid, consistency-valid
- verifier-passed
- `valuation_status=raw_quote`

The output is static and read-only. It does not run a server, database, wallet connection, upload, mint, signing flow, Helius call, or live network call.

The generated public files preserve receipt-scoped Coverage Statements and raw quote disclosures. They do not claim portfolio coverage, full history, trader skill, track record, prize eligibility, anti-wash validation, or USD-normalized PnL.

## Determinism

The build does not call Git and does not use a current timestamp. `--source-revision` is optional caller-supplied metadata. Repeated builds from identical inputs produce byte-identical files.

# v1.3 Regression Checklist

## Deterministic Regression Command

Run:

```bash
node engine/src/run-v13-regression.mjs
```

This should run:

- `engine/src/inventory/scanner.test.mjs`
- `engine/src/api/inventory-api.test.mjs`
- `engine/src/proof-detail/view-model.test.mjs`
- `engine/src/api/proof-detail-api.test.mjs`
- `engine/src/proof-export/render-static-page.test.mjs`
- `engine/src/api/proof-export-api.test.mjs`
- `engine/src/ledger/run-all-tests.mjs` (run separately when child-process execution is allowed)

The ledger runner is deterministic and local, but it shells out to child processes. The v1.3 wrapper keeps its own automation to direct in-process suites only and leaves the ledger runner as an explicit follow-up command.

## Final Review Checklist

- Confirm all v1.3 regression suites pass locally.
- Confirm `GET /api/inventory` returns v1.2 inventory only by default.
- Confirm `GET /api/inventory/summary` returns counts without mutating artifacts.
- Confirm `GET /api/proof/:receiptHash` returns grouped proof detail for known `receipt_hash` and `404` for unknown `receipt_hash`.
- Confirm `GET /api/proof/:receiptHash/export` returns standalone HTML for known `receipt_hash` and `404` for unknown `receipt_hash`.
- Confirm proof export includes selected-receipt-only framing.
- Confirm proof detail and proof export include the raw quote disclosure.
- Confirm legacy v1.1 inventory is not shown by default in UI or default proof routes.
- Confirm no upload, mint, signing, account, or hosting controls were added in v1.3 proof surfaces.
- Confirm generated/exported proof files are treated as local artifacts and not committed by default.

## Manual Smoke Checklist

### API

- Start the local server.
- Open `/api/inventory` and verify local v1.2 records appear.
- Open `/api/inventory/summary` and verify summary counts appear.
- Open `/api/proof/<known receipt_hash>` and verify grouped proof detail sections appear.
- Open `/api/proof/<unknown receipt_hash>` and verify `404`.
- Open `/api/proof/<known receipt_hash>/export` and verify standalone HTML renders.
- Open `/api/proof/<unknown receipt_hash>/export` and verify `404`.

### UI

- Load `/ui/` and verify the existing scanner flow still loads.
- Verify the local proof inventory section appears without replacing the existing scanner flow.
- Verify filters narrow the visible proof inventory entries.
- Verify clicking a receipt opens the matching proof detail.
- Verify `/ui/?receipt_hash=<known>` auto-opens the selected proof detail.
- Verify `/ui/?receipt_hash=<unknown>` shows a not-found proof detail state.
- Verify no legacy records appear by default.
- Verify no write/live-action controls appear.

### CLI / Export

- Run `node engine/src/proof-export/cli.mjs --receipt-hash <hash> --stdout` and verify HTML prints.
- Run `node engine/src/proof-export/cli.mjs --receipt-hash <hash> --output <path>` and verify the file is written.
- Run the CLI with an unknown `receipt_hash` and verify non-zero exit.

## Release Recommendation

- Tag `v1.3.0-rc1` if a final operator smoke pass is still pending.
- Tag `v1.3.0` once the deterministic regression runner and manual smoke checklist both pass.

## Retained format and result semantics

The original `artifact_final_episode_replay_v1` calibration profile remains accepted unchanged. Its two historical raw transaction bodies remain pinned and cannot be relabeled as final-agent evidence.

The additive `artifact_final_episode_replay_v2` uses the same flat bounded loader and descriptor field set. Its explicit evidence kinds are:

- `SYNTHETIC_FINAL_EPISODE`: fixed disposable offline wallet/profile; all newly synthesized observations and signatures are test evidence.
- `SUPERVISED_RETAINED_FINAL_EPISODE`: the fixed final-wallet scope, not arbitrary-wallet support. Admission is a supervised retained-provider-evidence boundary, not independent proof of the provider's truth or the host's custody.

Correction recorded with the fee-binding repair: the preceding discriminator was originally printed as `SUPERVISED_FINAL_EPISODE`. The implemented accepted spelling is `SUPERVISED_RETAINED_FINAL_EPISODE`; no alias or runtime behavior was added. Historical acceptance results and the independent read-only review remain unchanged. The pre-correction document is retained at `/root/artifact-final-fee-repair.nuueiz14/completion-before.md`; repair acceptance is recorded separately in `v1.3-final-episode-fee-binding-repair-closeout.md`.

`expected_evidence_kind` must agree with the manifest-bound descriptor. `control` is either a retained member reference or null. The control record contains the mandate, human authorization, configured principal/release bindings, at most two leg records, and optional authenticated revocation. Leg records retain challenge, decision, admission, signing identity, exact wire reference, original capture plus request/response references, submission member mapping, and optional finalized carrier. Referenced bytes are bounded and resolved before source replay.

The reconstruction result keeps these dimensions separate:

1. Package/member integrity and qualified source acquisition.
2. `eligibility`: original-boundary admission predicates.
3. `control`: retained authorization and agent provenance, reconstructed validator state and revocation.
4. `transmission`: consistency of retained signed/submission/terminal evidence; never economic authority.
5. `economic_observations`, `economic_availability`, complete population, explicit selection, and existing immutable claim where actually supported.
6. `demonstration` and the small `demo_summary`.

Economic observations are not transfer semantics or an economic claim. An existing state machine that has no finalized-failure closure state is not extended here: its last representable state remains available alongside independently established finalized failure. This does not mean known failure is relabeled as economic success or that a new attempt is authorized.

For incomplete supported packages, `claim` and `population` can be null and the original bridge dependency code is retained. Arbitrary exceptions are **not** converted into `BLOCKED` economic claims. Loader/format/source failures and selector/issuance exceptions remain distinct from an evaluated economic refusal. Existing evaluator outputs and explicit-selection semantics are preserved; even a singleton population is not automatically selected.

A complete synthetic proof can set `synthetic_demonstration_success` but **never** `full_demonstration_success`. Economics alone, invalid/missing provenance, revocation, failed or missing terminal evidence, or ineligible original opening cannot satisfy the complete demonstration contract. No output grants live authorization.

# v1.3 Release Notes

## Overview

v1.3 adds local, read-only proof surfaces around committed v1.2 proof artifacts.

This release does not change canonical v1.2 receipt, hash, verifier, upload, mint, valuation, or manifest logic. It packages those existing artifacts into local browsing, inspection, and export surfaces intended for release review and operator use.

## Slices Included

- Slice 1: local receipt inventory index
- Slice 2A: proof detail API and view-model
- Slice 3: local proof inventory UI inside the existing single-file local UI
- Slice 4: static proof export scaffold for one selected receipt
- Slice 5: release docs, deterministic regression runner, and release hardening

## New Local Proof Surfaces

### Inventory API

- `GET /api/inventory`
- `GET /api/inventory/summary`

These routes expose local v1.2 inventory records derived from committed canonical/debug artifacts. Legacy v1.1 inventory remains explicit and separate.

### Proof Detail API

- `GET /api/proof/:receiptHash`

This route returns grouped proof detail for one known v1.2 `receipt_hash`.

### Static Proof Export API

- `GET /api/proof/:receiptHash/export`

This route returns standalone static HTML for one selected receipt.

### Proof Export CLI

- `node engine/src/proof-export/cli.mjs --receipt-hash <hash> --stdout`
- `node engine/src/proof-export/cli.mjs --receipt-hash <hash> --output <path>`

The CLI resolves one local v1.2 receipt and renders a static proof page without hosting or network delivery.

## Local UI

The local UI now includes a read-only proof inventory and proof detail surface driven by the local APIs above.

UI scope remains local-only. It does not add hosted pages, account systems, or live proof actions.

## Scope Boundaries

v1.3 does not add:

- hosting or deployment
- account login or wallet linking
- proof wallet creation
- mainnet release support changes
- upload, minting, or signing actions through the new proof surfaces
- price fetching
- USD normalization
- Helius balance-at integration

## Important Disclosures

- Raw quote only. No USD normalization.
- Proof detail and proof export are selected-receipt-only views, not full track-record or portfolio statements.
- Legacy v1.1 inventory is not shown by default and remains explicit and separate.
- Generated/exported files are local artifacts and should not be committed unless intentionally curated.

## Regression Coverage

v1.3 release hardening adds `node engine/src/run-v13-regression.mjs`.

This runner executes:

- v1.3 inventory tests
- v1.3 proof detail tests
- v1.3 proof export tests
- the v1.3 deterministic suite set; the existing v1.2 ledger runner remains available as a separate local command when child-process execution is allowed

It does not require live Helius fetches, uploads, mints, signing, or secrets.

## Recommended Release Flow

1. Run `node engine/src/run-v13-regression.mjs`
2. Run local API/UI/manual smoke checks from `engine/docs/v1.3-regression-checklist.md`
3. Review `engine/docs/v1.3-limitations.md`
4. Tag `v1.3.0-rc1` if a final operator smoke pass is still desired
5. Tag `v1.3.0` once the smoke pass is complete

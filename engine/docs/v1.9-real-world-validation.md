## Hang Diagnosis

A prior long validation hang was caused by importing `server.mjs` before setting `TRADE_ARTIFACT_TEST=1`. That starts the standalone server listener and can leave an orphan listener on port 3000. The v1.9 archive demo checker sets `TRADE_ARTIFACT_TEST=1` before dynamic import, uses request and total timeouts, and closes the in-process server in `finally`.

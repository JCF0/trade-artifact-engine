## Implementation and privacy contract

`exchange.mjs:19–22` fixes production to `https://mainnet.helius-rpc.com/`. Its query constructor accepts only the reviewed policy fields, appends one internally URLSearchParams-encoded `api-key`, and adds neither Authorization nor X-Api-Key. Operator endpoint/query/authentication selectors, negotiation, redirect/retry/proxy fallback and automatic alternative credentials are unavailable. The separate loopback-only query helper is synthetic test plumbing, not a production endpoint override.

`binding.mjs:109–133` admits exactly the private shape `{capability_id, api_key, ca}`; the public and private ID must be `helius-mainnet-query-v1`. The conservative key grammar is `[A-Za-z0-9._~-]{16,4096}`, not a statement that every provider key format is supported. CA handling retains the existing bounded trust input. Closed-schema validation refuses proxies, accessors, extra fields, alternate capabilities and bearer/query mixtures before dispatch. Constructor and private-input exceptions are normalized without preserving their original message or cause. The private read buffer is wiped and FD 5 closed on success and refusal; descriptor ownership/identity/mode rules are unchanged. Complete erasure of JS strings, URL/TLS internals or arbitrary process memory is **not claimed**.

The original bearer helper/fixture path is retained for compatibility, but cannot serve as alternative production configuration for this binding. The production composition kernel remains private. The valid-preflight disabled-gate regression substitutes descriptor/release input only and confirms STOP before reading FD 5 or opening authority; it does not activate the production kernel.

The single bounded exchange preserves request Buffers and clean raw response bytes. It screens the raw key, base endpoint, constructed URL, request target and query forms; URI and standard/URL-safe base64 representations (padded/unpadded); and parsed JSON **keys and values**, including Unicode/slash escapes. At most **two ASCII percent-decoding layers** cover mixed/lowercase hex and escaped unreserved characters. This is a finite comparison/decoding contract, **not arbitrary covert-encoding protection**. Contaminated, malformed or otherwise inadmissible responses are refused before retention. No redaction, response reserialization or contamination quarantine/export is introduced.

The original bounded transport remains shared: one direct ClientRequest per call, exact body forwarding, TLS verification, header/stream caps, a single enclosing monotonic deadline, cancellation and connection cleanup, no hidden retries or redirect/proxy fallback. Screening completes inside that enclosing deadline. Root authority, SQLite consumption, journals, revocation, economic reconstruction, submission policy and scheduler source are unchanged. After contamination, a possible submission remains consumed/ambiguous; reopening returns identical retained evidence without a new provider operation.

**Simulation semantics are unchanged:** finalized commitment, unsigned wire, `sigVerify:false`, `replaceRecentBlockhash:false`. The Helius documentation discrepancy remains unresolved. No synthetic response or local TLS test qualifies actual Helius simulation behavior.

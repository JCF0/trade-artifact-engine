## Inventory Note

Runtime inventory output paths are fixed. A normal pipeline run overwrites the current runtime output inventory for the selected wallet. The current workflow cannot safely retain receipts from multiple wallet runs at the same time without a future deterministic multi-receipt inventory workflow.

For that reason, v1.8 does not edit the Historical Verified Receipt Board manifest to add the RAY receipt alongside the existing JUP board receipt.

# v1.5 Limitations

## Proof Scope

- Selected receipt only. Not a portfolio statement.
- Raw quote only. No USD normalization.
- Sample gallery is curated local sample browsing only. It is not a track-record or ranking surface.

## Rendering Scope

- Wallet display is render-only and may be `truncated`, `redacted`, or `full` depending on the local surface.
- Trust labels summarize local proof facts only. They do not add new verifier logic.
- Hosted preview remains local preview/scaffold semantics only.

## Out of Scope

v1.5 does not add:
- upload
- mint
- signing
- network verification
- remote hosting
- accounts
- profiles
- leaderboards
- wallet linking
- portfolio analytics
- USD normalization

## Automation Boundaries

- The v1.5 demo checker performs read-only local route checks only.
- It does not use browser automation, screenshots, export/publish write paths, or remote network calls.
- Existing v1.2 ledger child-process runner remains excluded from the consolidated regression wrapper.

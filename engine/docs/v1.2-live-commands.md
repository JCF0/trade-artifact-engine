# Trade Artifact Engine — v1.2 Live Command Reference

> **Security note:** Never paste real keypair paths, private keys, or `.env` contents into chat, logs, or version control. The commands below use `<placeholder>` values only.

## 1. Debug Pipeline Only (no upload, no mint)

```bash
node src/run-pipeline.mjs <WALLET_ADDRESS> --ledger-debug
```

This runs the full v1.2 debug chain:
- Position ledger → candidates → receipts → verifier
- Valuation context → preview → HTML → SVG images
- Metadata scaffold → upload package → dry-run
- Mint plan → mint-ready resolver
- E2E proof manifest

**No credentials required. No network calls beyond Helius transaction fetch.**

## 2. Single-Receipt Live Upload

```bash
UPLOAD_ENABLED=true \
IRYS_KEYPAIR_PATH=<path/to/irys-keypair.json> \
  node src/run-pipeline.mjs <WALLET_ADDRESS> --ledger-debug \
  --upload-live --upload-confirm \
  --upload-receipt-id <RECEIPT_ID>
```

### Required gates (all must pass):
- `--ledger-debug` — enables v1.2 debug chain
- `--upload-live` — enables live upload path
- `--upload-confirm` — explicit confirmation
- `--upload-receipt-id <id>` — single receipt selection
- `UPLOAD_ENABLED=true` — env gate
- `IRYS_KEYPAIR_PATH` — path to Irys funding keypair (file path only, contents never logged)
- Keypair file must exist at the specified path

### What it does:
1. Runs full debug pipeline
2. Uploads SVG image to Irys devnet
3. Builds final metadata (replaces placeholders with real URIs)
4. Uploads final metadata JSON to Irys devnet
5. Writes local final metadata + upload result manifest

### Post-upload verification:
```bash
# Check upload result manifest (public fields only)
node -e "const r=JSON.parse(require('fs').readFileSync('data/debug/ledger-upload-results-v12.json','utf-8')); console.log(JSON.stringify(r.results.map(e=>({id:e.receipt_id,status:e.upload_status,img:e.final_image_uri,meta:e.final_metadata_uri})),null,2))"
```

## 3. Single-Receipt Live Devnet Mint

```bash
MINT_ENABLED=true \
MINT_AUTHORITY_KEYPAIR_PATH=<path/to/mint-authority-keypair.json> \
  node src/run-pipeline.mjs <WALLET_ADDRESS> --ledger-debug \
  --mint-live --mint-confirm \
  --mint-receipt-id <RECEIPT_ID> \
  --proof-wallet <PROOF_WALLET_PUBKEY>
```

### Required gates (all must pass):
- `--ledger-debug` — enables v1.2 debug chain
- `--mint-live` — enables mint path
- `--mint-confirm` — explicit confirmation
- `--mint-receipt-id <id>` — single receipt selection
- `--proof-wallet <pubkey>` — explicit recipient (not inferred)
- `MINT_ENABLED=true` — env gate
- `MINT_AUTHORITY_KEYPAIR_PATH` — path to mint authority keypair
- Keypair file must exist
- Network must be devnet (default)
- Receipt must have complete upload with usable metadata URI
- Receipt must not already be minted

### Pre-mint checklist:
- Upload must be complete for the target receipt
- Mint authority wallet must have devnet SOL (≥0.02 SOL)
- Proof wallet pubkey must be a valid Solana address

### What it does:
1. Runs full debug pipeline + upload check
2. Checks mint authority balance (preflight)
3. Creates Token-2022 mint with NonTransferable extension
4. Creates associated token account for proof wallet
5. Mints 1 non-transferable proof token
6. Records mint result locally

### Post-mint verification:
```bash
# Check mint result manifest (public fields only)
node -e "const r=JSON.parse(require('fs').readFileSync('data/debug/ledger-mint-results-v12.json','utf-8')); console.log(JSON.stringify(r.results.map(e=>({id:e.receipt_id,status:e.mint_status,mint:e.mint_address,tx:e.transaction_signature})),null,2))"

# Check on Solana Explorer (devnet)
# https://explorer.solana.com/address/<MINT_ADDRESS>?cluster=devnet
```

## 4. Run All Tests

```bash
node src/ledger/run-all-tests.mjs
```

Runs all 18 test suites sequentially with a final summary.

## Environment Variables Summary

| Variable | Used by | Purpose |
|----------|---------|---------|
| `UPLOAD_ENABLED` | Upload gates | Must be `"true"` to allow live upload |
| `IRYS_KEYPAIR_PATH` | Irys uploader | File path to Irys keypair (never logged) |
| `IRYS_RPC_URL` | Irys uploader | Optional Solana RPC override |
| `MINT_ENABLED` | Mint gates | Must be `"true"` to allow live mint |
| `MINT_AUTHORITY_KEYPAIR_PATH` | Mint adapter | File path to mint authority keypair (never logged) |

**No env variable values are ever printed, logged, or stored in output manifests.**

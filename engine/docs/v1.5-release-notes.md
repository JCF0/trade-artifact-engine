# v1.5 Release Notes

## Summary

Artifact v1.5 closes the local proof-browsing layer with trust framing, verifier access, proof cards, curated sample gallery browsing, and deterministic regression coverage.

It adds:
- shared trust/disclosure helpers for proof surfaces
- compact verifier API for inventory-backed receipts
- proof card JSON and standalone HTML preview
- sample gallery JSON and standalone HTML preview
- v1.5 regression runner and read-only demo-flow checker

## What v1.5 Adds

v1.5 can now:
- derive trust level summaries from local proof facts
- expose verifier status in a compact API surface
- render a compact shareable proof card locally
- browse curated sample receipts locally through a gallery surface
- validate the documented demo flow through deterministic local checks

## Routes Added In v1.5

- `GET /api/verifier/:receiptHash`
- `GET /api/proof/:receiptHash/card`
- `GET /api/proof/:receiptHash/card/preview`
- `GET /api/gallery`
- `GET /api/gallery/preview`

## Key Commands

Regression:
- `node engine/src/run-v14-regression.mjs`
- `node engine/src/run-v15-regression.mjs`

Demo-flow checker:
- `node engine/src/check-v15-demo-flow.mjs`

## Platform Boundary

v1.5 is a local/shareable verification surface layer.
It is not a hosted platform, leaderboard, profile/account system, portfolio tracker, or competition product.

## Proof Scope Notes

- Selected receipt only. Not a portfolio statement.
- Raw quote only. No USD normalization.
- Wallet display remains render-only.
- Hosted preview remains local scaffold semantics only.

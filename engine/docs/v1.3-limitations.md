# v1.3 Limitations

## Scope

v1.3 is a local-only, read-only release layer around committed v1.2 proof artifacts.

It adds local inventory, proof detail inspection, local UI browsing, and static proof export. It does not change canonical v1.2 proof generation or live ledger behavior.

## Explicit Non-Goals

v1.3 does not add:

- hosting or deployment
- account login
- wallet linking
- proof wallet creation
- mainnet release orchestration
- upload
- minting
- signing
- price fetching
- USD normalization
- Helius balance-at integration

## Data Semantics

- Raw quote only. No USD normalization.
- `verification_status` remains separate from `hash_valid`, `verifier_passed`, and proof lifecycle fields.
- Proof detail and export surfaces are selected-receipt-only views, not portfolio-wide performance summaries.
- Legacy v1.1 inventory is not shown by default and remains explicit and separate.

## Inventory / Legacy Boundaries

Default v1.3 inventory uses committed v1.2 canonical/debug artifacts only.

Legacy v1.1 JSONL compatibility is:

- explicit
- separate from default v1.2 inventory lookup
- not shown in default UI
- not used by default proof detail or proof export lookup

## Artifact Handling

Generated or exported proof pages are local artifacts.

They should not be committed unless intentionally curated for documentation or fixture purposes.

## Operational Notes

- v1.3 surfaces assume local artifact availability.
- API and UI behavior are local-read-only convenience layers, not proof publication infrastructure.
- Static export HTML is share-ready in structure but is not hosted proof delivery.

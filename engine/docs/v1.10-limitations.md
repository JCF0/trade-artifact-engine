# Artifact v1.10 Limitations

Artifact v1.10 is a static public-demo readiness slice, not a production hosting or mainnet release.

## Public Demo Scope

- The bundle contains only publisher-selected JUP and RAY receipts.
- The board ranks receipts, not traders, wallets, portfolios, or skill.
- Coverage is receipt-scoped only.
- Valuation remains raw quote only. No USD normalization is performed or claimed.
- Wallets are truncated by default, but truncated public keys can still be correlatable on-chain.

## Hosting Scope

- The intended first host is Cloudflare Pages Direct Upload with the default `pages.dev` URL.
- No GitHub integration, custom domain, DNS change, Cloudflare Function, environment variable, or Cloudflare API automation is part of v1.10.
- A Cloudflare Pages Direct Upload project is a dedicated preview project and cannot later be converted to Git integration. Create a separate Git-backed project later if that becomes necessary.
- `robots.txt` and `X-Robots-Tag` reduce discovery only. They are not privacy, access control, authentication, or secrecy.

## Not Included

- No runtime server or dynamic API.
- No database or user submissions.
- No account system.
- No wallet connect flow.
- No signing, upload, minting, or mainnet transaction.
- No portfolio, full-history, trader-skill, track-record, anti-wash, prize, leaderboard, or USD-PnL claim.

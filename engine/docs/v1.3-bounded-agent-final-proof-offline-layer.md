# Artifact v1.3 bounded-agent final-proof offline layer

## Status

This layer is an offline-only proof of the authorization, agent-decision, executor-admission, evidence, and Artifact reconstruction boundaries. It contains no live provider, Solana key, transaction-builder, or submission entrypoint.

A production executor remains mechanically blocked until the mandate freezes all five live-readiness values:

- real human authorization public key;
- real agent-control public key;
- acquisition `not_after` Unix second;
- live RPC budget-table SHA-256;
- final Wiggles executor release SHA-256.

The fixed Ed25519 identities and signer in `final-proof-agent/fixtures/` are test-only. The offline executor core accepts injected fake capabilities and does not implement a Solana signer.

## Authority boundary

Agent provenance is never economic authority. The agent can only authenticate one of:

- `INITIATE_ACQUISITION`;
- `REFUSE_ACQUISITION`;
- `INITIATE_FULL_DISPOSAL`;
- `REFUSE_DISPOSAL`.

The agent cannot supply wallet, route, pool, mint, amount, slippage, transaction profile, tick arrays, blockhash, fee, rebroadcast policy, or disposal quantity. Disposal quantity is exactly `FINALIZED_CHAIN_DERIVED_COMPLETE_ACQUIRED_JUP_BALANCE`.

Human authorization and agent decisions use distinct domain-separated Ed25519 messages. Production modules expose exact-domain canonical-byte constructors and verifiers, but no signing endpoint. Fixed test signing helpers are confined to the offline fixture.

The trusted executor boundary independently binds:

```text
human authorization
→ mandate
→ current readiness challenge
→ unused authenticated agent decision
→ predecessor state
→ executor admission
→ prepared transaction commitment
→ signed transaction intent
```

Episode-ordinal consumption and authorization revocation are one injected atomic capability so a live successor can use crash-durable exclusive persistence. Uniqueness is keyed by episode and ordinal, not merely by a decision or challenge ID. The fixture proves concurrent-decision rejection across separate executor-core instances sharing that authority and proves that an atomically persisted revocation rejects a stale pre-revocation state snapshot. A final live release must provide one durable, linearizable authority shared by every executor instance.

## Evidence and economics

The closed evidence graph binds both legs through transmissions and finalized transaction identities into Artifact reconstruction. Its manifests use canonical JSON SHA-256 member identities and reject hash-inconsistent or cross-episode substitutions. Fully self-rehashed structural provenance remains non-authoritative unless the source-bound gate independently recaptures the corresponding authority.

`validateEpisodeEvidenceGraphStructureV1` is intentionally structural: internal hashes and cross-links establish provenance, not economic authority. Claim promotion is available only through the source-bound finalized-evidence adapter and source-reconstructing final gate validator.

The finalized-evidence adapter recaptures the existing source-bound v1.3 authority and recreates the existing production economic-evidence port. It checks finalized transaction identity, wallet, slot, block time, transaction digest, target continuity, exact acquisition USDC debit, and complete JUP disposal before exposing that port.

Economic values and the final `VERIFIED/CLOSED` claim are produced only by the existing:

- full-transaction projector;
- production Position economic-evidence bridge;
- episode population;
- explicit candidate selection;
- immutable claim issuer.

Mandate, authorization, decision, admission, and transmission records are provenance only.

The offline fixture's `closed_rebroadcast_evidence_sha256` and `terminal_resolution_evidence_sha256` values are deterministic synthetic provenance references, not source-authenticated scheduler archives. They cannot promote or determine economics. A live successor must retain the exact signed wire and complete reviewed-scheduler/terminal evidence and add an independently validated source boundary for those child artifacts; the current offline gate deliberately remains live-blocked and must not be represented as proving those live transmission children.

The offline fixture is a deterministic synthetic authority derived from the frozen controlled mainnet Whirlpool transactions but rebound to the final-proof public wallet/account identities. It does not claim that those synthetic transactions occurred onchain.

## Reviewed reusable components

The exact reviewed identical-byte scheduler and transaction-error validator are vendored byte-for-byte under `final-proof-agent/reused/`. `REVIEWED-SOURCE.json` binds their source archive and file hashes. Tests reject any drift and bind the scheduler's three-send, zero-provider-retry policy.

The existing setup and calibration archives remain immutable predecessors and were not modified.

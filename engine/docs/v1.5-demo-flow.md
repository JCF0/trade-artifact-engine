# v1.5 Demo Flow

## Source of Demo Receipt

Use the tracked sample manifest:
- `engine/samples/sample-gallery.manifest.json`

Take the first `receipt_hash` in that file as the demo receipt.
That hash must also exist in local inventory for the documented checker and manual flow.

## Operator Walkthrough

1. Open `GET /api/gallery`.
Expected:
- JSON gallery response
- at least one curated sample item
- selected-receipt and raw-quote disclosures

2. Open `GET /api/gallery/preview`.
Expected:
- standalone local HTML gallery page
- compact item cards
- no hosted-platform, leaderboard, profile, portfolio, or mainnet-product framing

3. Copy the first sample `receipt_hash` from the gallery item.
Expected:
- hash matches the tracked sample manifest
- hash is present in local inventory

4. Open `GET /api/proof/:receiptHash`.
Expected:
- full proof detail JSON for the selected receipt
- trust/disclosure fields present

5. Open `GET /api/verifier/:receiptHash`.
Expected:
- compact verifier JSON
- no legacy fallback
- local inventory-backed framing
- no hosted-platform, profile, leaderboard, or portfolio semantics

6. Open `GET /api/proof/:receiptHash/card`.
Expected:
- compact proof-card JSON
- no lifecycle/upload/mint grids

7. Open `GET /api/proof/:receiptHash/card/preview`.
Expected:
- standalone local HTML proof card
- title, trust label, receipt hash short form, verifier path, disclosures
- redacted and truncated wallet display modes render correctly when requested

8. Open `GET /api/proof/:receiptHash/hosted-preview`.
Expected:
- standalone local hosted-style proof page
- hosted preview semantics only
- raw quote and selected-receipt disclosures remain intact
- no remote hosting, profile, portfolio, leaderboard, mainnet, or privacy guarantees are implied

9. Optionally open `GET /api/proof/:receiptHash/export`.
Expected:
- standalone local static proof page
- export scaffold semantics only

## Disclosures To Confirm

Across the flow, confirm:
- `Selected receipt only. Not a portfolio statement.`
- `Raw quote only. No USD normalization.`
- wallet redaction/truncation choices remain render-only display policy

Also confirm the flow does not imply:
- hosted platform delivery
- ranking or competition
- profile/account ownership
- full track-record or portfolio claims
- mainnet or USD-normalized product semantics

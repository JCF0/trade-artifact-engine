# v1.8 Regression Checklist

Run from the repository root.

## Required Commands

```bash
node engine/src/run-v18-regression.mjs
node engine/src/run-v17-regression.mjs
node engine/src/run-v16-regression.mjs
node engine/src/run-v15-regression.mjs

```

## Required v1.8 Checks

The v1.8 regression must verify:
- two same-mint inputs into one output succeeds
- three same-mint inputs into one output succeeds
- integer raw amounts are summed before decimal normalization
- diagnostic input references are preserved only in helper diagnostics
- canonical-facing normalized events do not include diagnostic metadata or input refs
- mixed input mints fail closed
- multiple output transfers fail closed, even when output mints match
- native plus token input fails closed
- same input and output mint fails closed
- ambiguous ownership fails closed
- unexplained extra wallet-side assets fail closed
- ingest, normalize, classifier, and run-pipeline paths accept the same safe shape
- legacy strict one-input / one-output fixtures remain unchanged
- the accepted fixture moves from `multi_leg` classification to processable classification
- the real-shape RAY fixture produces exactly one `events_swap_same_mint_aggregated` event

## Deterministic Exclusions

Do not include:
- live Helius fetches
- upload, mint, or signing
- browser automation
- remote deployment
- mutable-cache pipeline tests
- child-process ledger runner

The ledger runner remains separate:

```bash
node engine/src/ledger/run-all-tests.mjs
```

## Compatibility Checks

Confirm v17, v16, v15, and v14 regressions remain green. v1.8 must preserve coverage behavior, verified-only board eligibility, canonical receipt schema, verifier logic, accounting, ledger schema, manifest selection, and proof surfaces.

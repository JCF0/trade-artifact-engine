# Artifact v1.9 Release Notes

Artifact v1.9 adds deterministic multi-receipt local inventory through a receipt archive. Receipts from separate wallet pipeline runs can coexist locally without manual copying and without changing canonical receipt records.

## Added

- Deterministic receipt archive bundles under the existing gitignored `engine/data` area.
- Current-run archive import via `node engine/src/inventory/archive-current-run.mjs`.
- Archive-backed inventory scanning behind `includeArchive: true`.
- Targeted archive-backed resolution for proof detail, verifier, proof card, card preview, static export, hosted preview, and the Historical Verified Receipt Board.
- v1.9 regression runner: `node engine/src/run-v19-regression.mjs`.
- Archive-aware demo checker: `node engine/src/check-v19-archive-demo.mjs`.

## Validation

Real local validation imported receipts from separate JUP and RAY wallet runs. The archive contained 66 receipts with zero diagnostics. Both selected verified closed-position receipts resolved through proof detail, verifier, proof card, card preview, static export, hosted preview, and the receipt board.

## Compatibility

Existing stored receipts are not rewritten. Canonical receipt hashes, verifier behavior, accounting, normalization, coverage statements, board eligibility, and ranking remain unchanged.

Default inventory APIs remain current-snapshot-only. Archive resolution is intentionally targeted to proof and receipt-board surfaces.

## Non-goals

v1.9 does not add upload, mint, signing, accounts, profiles, remote hosting, remote database storage, raw wallet history retention, USD normalization, PnL ranking, portfolio claims, track-record claims, or trader-skill claims.

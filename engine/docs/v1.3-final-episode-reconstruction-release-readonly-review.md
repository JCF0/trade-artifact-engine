## 2. Findings

### B1 — High: successful final demonstration does not require finalized fee agreement with the authorized exact-message fee

**Location:** `A/retained-final-control-v1.mjs:131-158,191-205`, consumed by `A/final-episode-release-v1.mjs:185-192`.

The retained-control evaluator rebuilds the exact message plan and verifies retained wire/signature identities. The plan carries the mandate's per-leg fee, and readiness verifies `getFeeForMessage` against that value (`A/orca-message-boundary-v1.mjs:35-36,68-74`; `A/orca-readiness-capture-v1.mjs:294-308`). However, when the independently loaded finalized transaction is joined to that plan, the evaluator checks wire/message identity, time and token deltas, but never compares `tx.fee_lamports` with the plan/captured/mandated fee. The finalized-leg record it creates does not include a separate fee constraint.

Other layers do not supply the missing cross-binding:

- `engine/src/wallet-acquisition/helius-full-transaction-validator.mjs:149-156,170-181` validates fee/balance shape and retains their values, not their agreement with this episode's mandate.
- `V/production-position-economic-evidence-bridge-v1-3.mjs:109-120` requires the wallet native delta to equal the transaction's own reported fee. It has no mandate/capture input and correctly does not enforce executor authorization.
- `A/wiggles-submission-v1.mjs:167-178` and `A/reused/bounded-rebroadcast-v1.mjs:212` reconcile terminal status/error and exact signed payload, not finalized fees against the captured message fee.
- `A/retained-final-control-v1.mjs:193-195` compares the two retained finalized bodies to each other. Both can agree with each other while contradicting the unchanged capture and mandate.
- The complete-demonstration conjunction at `A/final-episode-release-v1.mjs:185-192` therefore has no gate for this contradiction.

**Concrete static counterexample (not executed, per review restrictions):** start with the complete selected synthetic episode represented by `A/final-episode-integration-v1.test.mjs:28-46` and `A/fixtures/retained-final-episode-v1.mjs:44-49,127-161`. In the disposal finalized response, change `meta.fee` from 5000 to 5001 and wallet `postBalances[0]` from 810624 to 810623, preserving its 815624 pre-balance and every token effect. Apply the same change to the terminal retained finalized response. Recompute the affected unsigned response-retention/normalized/manifest/checksum/completion references and outer package hashes. Set the optional disposal `leg.finalized` carrier to null (expressly permitted by line 200), or recompute that unsigned carrier; recreate the explicit population/member selection for the altered source.

Leave the human authorization, agent decisions, challenges, captured fee responses, signed intent, signed message and signed wire unchanged. In particular, no new signature is needed: transaction metadata is not part of the signed message. Using the disposal leg avoids changing the finalized acquisition digest committed by the second decision.

The source economic checks still see an otherwise valid round trip and a native delta exactly equal to the altered reported fee. Capture still establishes a 5000-lamport fee; wire identity still matches; both terminal bodies agree; the final control state can still close. No inspected predicate rejects the 5001-versus-5000 contradiction before `contract_satisfied` / synthetic success. The same missing predicate is shared by the supervised-profile demonstration calculation. This is an internally inconsistent evidence acceptance path, not a claim that changing a hash proves provider truth or that the hypothetical transaction occurred onchain.

**Impact:** an episode that contradicts the human-authorized exact per-leg fee/rent contract can be presented as a successful complete demonstration. The frozen requirement is explicit at `engine/docs/v1.3-construct-supervised-release-checklist.md:62`. A provider/custody disclaimer does not excuse accepting a contradiction between two retained inputs already available to this verifier.

**Essential missing regression:** an end-to-end, otherwise valid two-leg retained package with the finalized disposal fee and native debit changed together, the terminal body and all unsigned dependent hashes refreshed, but the authenticated mandate and captured exact-message fee unchanged. Require an explicit contradictory/invalid demonstration disposition and both demonstration-success flags false. Keep economic-claim semantics separate: the fix need not redefine v1.3 quote economics or make agent provenance economic authority. Cover matching-fee success and the failed/acquisition-only counterparts at the same reconciliation boundary.
